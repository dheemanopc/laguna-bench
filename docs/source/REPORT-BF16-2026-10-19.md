# Laguna S 2.1 at BF16: Faithfulness, Planning and Cost Report

**Run window:** 2026-10-18 22:39 to 2026-10-19 03:32 IST
**Feature tested:** F2 "team workflows + board" on mem-mcp (open source)
**Question:** can self-hosted Laguna S 2.1 at full precision be the team's faithful implementer, with Sonnet planning and reviewing?

## 1. Verdict

| Bar | Result |
|---|---|
| **Faithful implementation** (honest claims, stays in scope, never weakens checks) | **PASS in every valid sample.** No false "tests pass" claims, no out-of-scope edits, and no `type: ignore`, `noqa`, skip or xfail added. fp4 added `type: ignore` on the same task. |
| **Correct implementation** | **Needs review.** The Sonnet WP1 milestone review found 5 real authorization and integrity defects, even though every gate was green. |
| **Planning / design** | **Draft only.** One-shot design doc scored 5.5/10 and the WP1 task plan 6.5/10, both "revise". It must not decide security or schema questions. |
| **Cost-effectiveness** | **Only when shared.** The box ran at about 10% of capacity, so the effective cost was about $3–5 against a $29.6 bill. |

**Recommendation:** go ahead with the team-shared self-host, using this split:
- Sonnet plans and reviews every package against the code.
- Laguna BF16 implements, tests and commits.
- Run the harness next to the GPUs, never through a laptop tunnel.

## 5. Infrastructure finding

- **Tunnel stalls:** with 5 to 7 parallel sessions on one laptop SSH tunnel, the tunnel stalled **13 times** after 23:00 IST. It never stalled with a single session.
- **Stalls cost whole attempts:** a stalled request hangs until the 1-hour task timeout.
- **The box was not the problem:** it stayed healthy throughout (98% GPU, about 115 tok/s single stream).
- **Rule for the team deployment:** harness and agents must be co-located with the GPUs (same VPC or host).

## 6. Utilisation and cost

| Metric | Value |
|---|---|
| Box lifetime | about 293 min: 14 boot, 272 serving, 7 after done |
| Requests active | 225 min. The remaining 68 min were fully idle, about $6.70. |
| Average concurrency | 1.8 sessions, against about 15 possible at 262k |
| KV cache used | 4.3% average, 9.9% peak |
| Generation | 2.19M tokens, 134 tok/s average (350 peak), against an estimated 1,000–1,500 tok/s capacity (not benchmarked) |
| Capacity used | **about 10%** |
| Bill | about $29 box plus $0.59 Claude (milestone review and acceptance), **about $29.6 total** |
| Effective cost at full sharing | **about $3–5** |

**Economics:** self-hosting is cheap per task only at about 10 or more concurrent sessions, which needs team-scale load and a co-located harness. At single-user occupancy it costs about 6 to 8 times more per task.
