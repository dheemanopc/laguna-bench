  Additional bugs found

  - Notice payload is double-encoded. queue() calls json.dumps, and the pool's jsonb codec dumps it again, so payload is stored as a JSON string scalar (jsonb_typeof = 'string'), not an object. deliver_pending's
    isinstance(str) branch hides this. Test: test_BUG_queue_stores_payload_as_json_object.
  - deliver_pending doesn't return oldest-first. The inner ORDER BY created_at only chooses which rows to claim; UPDATE … RETURNING order is unspecified. I observed non-sorted order with both 2 and 12 rows. Test:
    test_BUG_deliver_returns_oldest_first, with 12 scrambled inserts so a lucky sorted result is very unlikely. The set of rows claimed with limit is the oldest N, and that is pinned by passing tests.
  - Cursor with empty parts is ignored. A cursor of ["", ""] skips the predicate silently instead of returning -32602. Test: test_BUG_cursor_with_empty_parts_is_rejected.
  - _decode_cursor accepts non-[str, str] payloads. "abc" decodes to ('a', 'b') and [1, 2] decodes to (1, 2). These are covered by the unit xfails listed under bug 4.
