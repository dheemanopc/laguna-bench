● I approved WP0 in round 2; the review is in orders/review-wp0-2.md.

  The gate is clean: no new test failures, ruff and mypy pass, and there is one migration head. All four code problems from round 1 are fixed, and the seven planned tests now exist.

  Two points need action, though neither blocks this stage:
  - NOT NULL on work_items.workflow_id is left hanging. The migration leaves the column nullable and says WP1 will make it NOT NULL, but the WP1 section of the plan never mentions it. The WP1 order needs to require a new
    migration that back-fills and then sets NOT NULL. It also needs mark_work_item to fill in the column, and a default workflow for teams created after this migration. Without that, new items get no workflow version.
  - Access grants go beyond the plan. The migration grants DELETE on work_items and UPDATE on work_item_history, and downgrade() never removes them. That leaves the "history can't be edited" rule resting on a single
    database policy.

  Two smaller test gaps are also noted:
  - The seed and back-fill tests re-run copies of the SQL on fresh teams, so they don't prove that teams which already existed got a workflow.
  - The cross-team test only checks that an outsider can't read another team's item, not that they can't change it or add history to it.
